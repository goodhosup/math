# 2. 다항식의 나눗셈

> **먼저 알아야 할 것**: [1. 다항식의 덧셈·뺄셈·곱셈](01-polynomials.md)
>
> **한 줄 요약**: 다항식도 숫자처럼 나눌 수 있고, 결과는 항상 "나누는 식 × 몫 + 나머지" 꼴입니다.

## 숫자 나눗셈부터 떠올려 봐요

$17 \div 5$는 몫이 3, 나머지가 2입니다. 이것을 곱셈으로 쓰면

$$
17 = 5 \times 3 + 2
$$

이 모양이 핵심입니다. **나눠지는 수 = 나누는 수 × 몫 + 나머지**, 그리고 나머지는 나누는 수보다 작아야 합니다.

다항식도 똑같습니다.

$$
A = B \times Q + R
$$

- $A$: 나눠지는 식
- $B$: 나누는 식
- $Q$: 몫
- $R$: 나머지 ($R$의 차수는 $B$의 차수보다 **낮아야** 합니다)

## 직접 나눠 보기 (세로 나눗셈)

$(x^2 + 5x + 7) \div (x + 2)$를 해 봅시다. 원리는 "**맨 앞 항을 없애는 것을 반복**"입니다.

**1단계.** 맨 앞 $x^2$을 없애려면 $(x + 2)$에 무엇을 곱해야 할까요? $x$입니다.

$$
(x + 2) \times x = x^2 + 2x
$$

이것을 빼면

$$
(x^2 + 5x + 7) - (x^2 + 2x) = 3x + 7
$$

**2단계.** 이제 맨 앞 $3x$를 없애려면 $(x + 2)$에 $3$을 곱합니다.

$$
(x + 2) \times 3 = 3x + 6
$$

빼면

$$
(3x + 7) - (3x + 6) = 1
$$

**3단계.** 남은 $1$은 $(x + 2)$보다 차수가 낮으므로 더 나눌 수 없습니다. 끝!

몫은 1단계와 2단계에서 곱한 것을 더한 $x + 3$, 나머지는 $1$입니다.

$$
x^2 + 5x + 7 = (x + 2)(x + 3) + 1
$$

> 💡 **확인 방법**: 오른쪽을 전개해서 왼쪽과 같은지 보세요. $(x + 2)(x + 3) + 1 = x^2 + 5x + 6 + 1$ ✔

세로셈으로 정리하면 이렇습니다.

| 단계 | 몫에 쓸 것 | 곱한 결과 | 빼고 남은 것 |
|---|---|---|---|
| 시작 | | | $x^2 + 5x + 7$ |
| 1 | $x$ | $x^2 + 2x$ | $3x + 7$ |
| 2 | $+3$ | $3x + 6$ | $1$ |

### 빠진 차수는 0으로 채우세요

$(x^3 - 1) \div (x - 1)$처럼 중간 차수가 없으면 $x^3 + 0x^2 + 0x - 1$로 써 놓고 나누면 줄이 어긋나지 않습니다.

## 조립제법: $(x - a)$로 나눌 때의 지름길

나누는 식이 $x - a$ 꼴(일차식)이면 **계수만 가지고** 빠르게 나눌 수 있습니다.

$(2x^3 - 3x^2 + 4x - 5) \div (x - 1)$을 해 봅시다. $a = 1$입니다.

1. 맨 위 줄에 계수 $2, -3, 4, -5$를 적고, 왼쪽에 $a = 1$을 적습니다.
2. 첫 계수 $2$를 그대로 내립니다.
3. 내린 수에 $a$를 곱해 다음 칸 위에 더합니다. 이것을 반복합니다.

| $a = 1$ | $2$ | $-3$ | $4$ | $-5$ |
|---|---|---|---|---|
| 더할 값 ($\times 1$) | | $2$ | $-1$ | $3$ |
| 결과 | $2$ | $-1$ | $3$ | $\boldsymbol{-2}$ |

- 마지막 칸 $-2$가 **나머지**
- 나머지 앞의 $2, -1, 3$이 **몫의 계수** → 몫은 $2x^2 - x + 3$

$$
2x^3 - 3x^2 + 4x - 5 = (x - 1)(2x^2 - x + 3) - 2
$$

> 💡 $x + 2$로 나눌 때는 $x - (-2)$이므로 $a = -2$를 씁니다. 부호에 주의하세요.

## 예제

**예제 1.** $(x^2 - 3x + 5) \div (x - 1)$의 몫과 나머지를 구하세요.

> 풀이: $x$를 곱하면 $x^2 - x$, 빼면 $-2x + 5$
>
> $-2$를 곱하면 $-2x + 2$, 빼면 $3$
>
> 몫 $x - 2$, 나머지 $3$

**예제 2.** 조립제법으로 $(x^3 + 2x^2 - x + 4) \div (x + 2)$의 몫과 나머지를 구하세요.

> 풀이: $a = -2$, 계수 $1, 2, -1, 4$
>
> | $a = -2$ | $1$ | $2$ | $-1$ | $4$ |
> |---|---|---|---|---|
> | 더할 값 | | $-2$ | $0$ | $2$ |
> | 결과 | $1$ | $0$ | $-1$ | $6$ |
>
> 몫 $x^2 - 1$, 나머지 $6$

**예제 3.** 어떤 다항식을 $x + 1$로 나누었더니 몫이 $x - 3$, 나머지가 $2$였습니다. 이 다항식은?

> 풀이: $A = B \times Q + R$ 이므로 $(x + 1)(x - 3) + 2 = x^2 - 2x - 3 + 2 = x^2 - 2x - 1$

## 연습문제

1. $(x^2 + 7x + 10) \div (x + 2)$의 몫과 나머지
2. $(x^2 + 4x + 1) \div (x + 3)$의 몫과 나머지
3. $(2x^2 - x + 3) \div (x - 2)$의 몫과 나머지
4. 조립제법: $(x^3 - 2x^2 + 3x - 1) \div (x - 1)$
5. 조립제법: $(x^3 - 8) \div (x - 2)$
6. 다항식 $A$를 $x - 2$로 나눈 몫이 $x^2 + 1$, 나머지가 $3$일 때 $A$를 구하세요.

## 정답과 풀이

1. 몫 $x + 5$, 나머지 $0$ (나누어떨어짐: $x^2 + 7x + 10 = (x + 2)(x + 5)$)
2. 몫 $x + 1$, 나머지 $-2$ ($(x + 3)(x + 1) = x^2 + 4x + 3$, 차이 $-2$)
3. 몫 $2x + 3$, 나머지 $9$ ($2x$를 곱해 빼면 $3x + 3$, $3$을 곱해 빼면 $9$)
4. 몫 $x^2 - x + 2$, 나머지 $1$ (결과 줄: $1, -1, 2, 1$)
5. 몫 $x^2 + 2x + 4$, 나머지 $0$ (계수 $1, 0, 0, -8$ → 결과 $1, 2, 4, 0$)
6. $A = (x - 2)(x^2 + 1) + 3 = x^3 - 2x^2 + x + 1$
