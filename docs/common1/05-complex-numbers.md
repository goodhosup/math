# 5. 복소수

> **먼저 알아야 할 것**: [0단계 6. 제곱근과 무리수](../basics/06-square-roots.md), [1. 다항식의 덧셈·뺄셈·곱셈](01-polynomials.md)
>
> **한 줄 요약**: 제곱해서 $-1$이 되는 수 $i$를 새로 만들면, 모든 이차방정식에 답이 생깁니다.

## 제곱해서 음수가 되는 수?

[0단계](../basics/06-square-roots.md)에서 "음수의 제곱근은 없다"고 했습니다. 실제로 지금까지 배운 수(**실수**)는 제곱하면 항상 0 이상이니까요.

그런데 수학자들은 이렇게 생각했습니다. "없으면 **새로 만들자**."

$$
i^2 = -1
$$

이 되는 수 $i$를 **허수단위**라고 정합니다. ($i$는 imaginary, "상상의"의 첫 글자)

> 💡 음수가 처음 나왔을 때도 사람들은 "0보다 작은 수가 어디 있냐"고 했습니다. 하지만 빚, 영하 온도를 나타내는 데 아주 유용했지요. $i$도 마찬가지로 전기공학, 물리학에서 없어서는 안 되는 수입니다.

## 음수의 제곱근

$i$를 쓰면 음수의 제곱근을 나타낼 수 있습니다. $a > 0$일 때

$$
\sqrt{-a} = \sqrt{a}\,i
$$

$$
\sqrt{-4} = 2i, \qquad \sqrt{-3} = \sqrt{3}\,i
$$

$-9$의 제곱근은 $\pm 3i$입니다. 확인: $(3i)^2 = 9i^2 = -9$ ✔

## 복소수 $a + bi$

실수 $a$, $b$로 $a + bi$ 꼴로 나타낸 수를 **복소수**라고 합니다.

- $a$: **실수부분**
- $b$: **허수부분**

| 예 | 실수부분 | 허수부분 | 종류 |
|---|---|---|---|
| $3 + 2i$ | $3$ | $2$ | 허수 |
| $-5i$ | $0$ | $-5$ | 순허수 |
| $7$ | $7$ | $0$ | 실수 |

실수도 허수부분이 $0$인 복소수입니다. 즉 복소수는 지금까지의 모든 수를 포함하는 더 큰 수의 세계예요.

### 복소수가 같을 조건

$$
a + bi = c + di \iff a = c \text{ 이고 } b = d
$$

실수부분끼리, 허수부분끼리 같아야 합니다.

## 복소수의 계산: $i$를 문자처럼

$i$를 $x$ 같은 문자처럼 계산하다가, **$i^2$이 나오면 $-1$로 바꾸면** 됩니다.

**덧셈·뺄셈**: 실수부분끼리, 허수부분끼리

$$
(3 + 2i) + (1 - 5i) = 4 - 3i
$$

**곱셈**: 전개하고 $i^2 = -1$

$$
(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i
$$

### 켤레복소수

$a + bi$에서 허수부분의 부호만 바꾼 $a - bi$를 **켤레복소수**라고 하고 $\overline{a + bi}$로 씁니다.

서로 켤레인 두 수를 곱하면 **실수**가 됩니다.

$$
(a + bi)(a - bi) = a^2 - b^2 i^2 = a^2 + b^2
$$

**나눗셈**: 분모의 켤레복소수를 위아래에 곱해서 분모를 실수로 만듭니다. ([분모의 유리화](../basics/06-square-roots.md)와 같은 아이디어예요.)

$$
\frac{1 + i}{1 - i} = \frac{(1 + i)(1 + i)}{(1 - i)(1 + i)} = \frac{1 + 2i + i^2}{1 + 1} = \frac{2i}{2} = i
$$

## $i$의 거듭제곱: 4개씩 반복

$$
i^1 = i, \quad i^2 = -1, \quad i^3 = -i, \quad i^4 = 1
$$

$i^4 = 1$이므로 그다음부터는 $i, -1, -i, 1$이 계속 반복됩니다. 그래서 지수를 4로 나눈 나머지만 보면 됩니다.

$$
i^{10} = i^{4 \times 2 + 2} = i^2 = -1
$$

## 주의: $\sqrt{a}\sqrt{b} = \sqrt{ab}$가 깨질 때

$$
\sqrt{-2} \times \sqrt{-3} = \sqrt{2}i \times \sqrt{3}i = \sqrt{6}\,i^2 = -\sqrt{6}
$$

$\sqrt{(-2)(-3)} = \sqrt{6}$이 **아닙니다!** 음수가 루트 안에 있으면 **먼저 $i$로 꺼낸 다음** 계산하세요.

## 예제

**예제 1.** $(4 - i) - (1 - 3i)$

> 풀이: $4 - i - 1 + 3i = 3 + 2i$

**예제 2.** $(1 + 2i)^2$

> 풀이: $1 + 4i + 4i^2 = 1 + 4i - 4 = -3 + 4i$

**예제 3.** $\dfrac{5}{2 + i}$

> 풀이: $\dfrac{5(2 - i)}{(2 + i)(2 - i)} = \dfrac{5(2 - i)}{4 + 1} = 2 - i$

**예제 4.** $(x - 1) + (y + 2)i = 3 - i$를 만족하는 실수 $x$, $y$는?

> 풀이: $x - 1 = 3$, $y + 2 = -1$ 이므로 $x = 4$, $y = -3$

## 연습문제

1. $\sqrt{-16}$과 $\sqrt{-5}$를 $i$를 써서 나타내세요.
2. $(2 + 5i) + (3 - 2i)$
3. $(3 - i)(2 + 4i)$
4. $(1 - i)^2$
5. $\overline{4 - 3i}$와 $(4 - 3i)\,\overline{(4 - 3i)}$
6. $\dfrac{3 + i}{1 + i}$
7. $i^{2026}$
8. $\sqrt{-4} \times \sqrt{-9}$
9. $(2x - y) + (x + y)i = 1 + 5i$를 만족하는 실수 $x$, $y$

## 정답과 풀이

1. $4i$, $\sqrt{5}\,i$
2. $5 + 3i$
3. $10 + 10i$ ($6 + 12i - 2i - 4i^2 = 6 + 10i + 4$)
4. $-2i$ ($1 - 2i + i^2$)
5. $4 + 3i$, $25$ ($16 + 9$)
6. $2 - i$ ($\dfrac{(3 + i)(1 - i)}{2} = \dfrac{3 - 3i + i - i^2}{2} = \dfrac{4 - 2i}{2}$)
7. $-1$ ($2026 = 4 \times 506 + 2$이므로 $i^2$)
8. $-6$ ($2i \times 3i = 6i^2$)
9. $x = 2$, $y = 3$ ($2x - y = 1$, $x + y = 5$를 더하면 $3x = 6$)
