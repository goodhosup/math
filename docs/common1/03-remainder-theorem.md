# 3. 항등식과 나머지정리

> **먼저 알아야 할 것**: [2. 다항식의 나눗셈](02-division.md)
>
> **한 줄 요약**: $f(x)$를 $x - a$로 나눈 나머지는 **나눌 필요 없이** $f(a)$만 계산하면 됩니다.

## 항등식: $x$에 무엇을 넣어도 참인 등식

$$
(x + 1)^2 = x^2 + 2x + 1
$$

이 등식은 $x$에 1을 넣든 100을 넣든 항상 참입니다. 이런 등식을 **항등식**이라고 합니다.

반면 $2x + 1 = 7$은 $x = 3$일 때만 참이므로 방정식입니다.

> 💡 문제에 "**모든 $x$에 대하여**", "**$x$의 값에 관계없이**"라는 말이 있으면 항등식입니다.

### 항등식의 성질: 계수가 같다

$ax^2 + bx + c = 2x^2 + 3x - 1$이 항등식이면, 양쪽의 같은 차수 계수가 모두 같아야 합니다.

$$
a = 2, \quad b = 3, \quad c = -1
$$

### 미정계수 구하는 두 가지 방법

$x^2 + ax + 3 = (x - 1)(x + b) + 5$가 항등식일 때 $a$, $b$를 구해 봅시다.

**방법 1. 계수 비교법**: 오른쪽을 전개해서 계수를 맞춥니다.

$$
(x - 1)(x + b) + 5 = x^2 + (b - 1)x + (5 - b)
$$

상수항: $3 = 5 - b$ 이므로 $b = 2$. $x$의 계수: $a = b - 1 = 1$

**방법 2. 수치 대입법**: 아무 $x$나 넣어도 성립하니, 계산이 쉬워지는 값을 넣습니다.

$x = 1$을 넣으면 $(x - 1)$이 0이 되어서 $1 + a + 3 = 5$, 따라서 $a = 1$

$x = 0$을 넣으면 $3 = (-1)(b) + 5$, 따라서 $b = 2$

## 나머지정리

$f(x)$를 $x - a$로 나눈 몫을 $Q(x)$, 나머지를 $R$이라고 하면

$$
f(x) = (x - a)\,Q(x) + R
$$

이 식은 항등식이니까 $x = a$를 넣어도 됩니다. 그러면 $(x - a)$가 $0$이 되어서

$$
f(a) = 0 \times Q(a) + R = R
$$

즉,

$$
f(x)\text{를 } x - a \text{로 나눈 나머지} = f(a)
$$

이것이 **나머지정리**입니다. 나눗셈을 직접 하지 않아도 숫자 하나만 넣으면 나머지가 나옵니다!

> 💡 $x - a = 0$이 되는 $x$를 넣는다고 기억하세요.
>
> - $x - 2$로 나눈 나머지 → $f(2)$
> - $x + 3$으로 나눈 나머지 → $f(-3)$
> - $2x - 1$로 나눈 나머지 → $f\!\left(\dfrac{1}{2}\right)$

**예)** $f(x) = x^3 - 2x + 5$를 $x - 2$로 나눈 나머지는

$$
f(2) = 8 - 4 + 5 = 9
$$

## 인수정리: 나머지가 0이면

나머지가 $0$이라는 것은 **나누어떨어진다**는 뜻이지요. 그러면 $x - a$는 $f(x)$의 인수입니다.

$$
f(a) = 0 \iff f(x) \text{는 } x - a \text{로 나누어떨어진다} \iff f(x) = (x - a)\,Q(x)
$$

이것을 **인수정리**라고 합니다. 다음 단원 인수분해에서 핵심 도구로 쓰입니다.

**예)** $f(x) = x^3 - 6x^2 + 11x - 6$에서 $f(1) = 1 - 6 + 11 - 6 = 0$이므로 $f(x)$는 $x - 1$로 나누어떨어집니다.

## 예제

**예제 1.** $f(x) = 2x^3 + x^2 - 3$을 $x + 1$로 나눈 나머지는?

> 풀이: $f(-1) = -2 + 1 - 3 = -4$

**예제 2.** $x^3 + ax + 4$가 $x - 2$로 나누어떨어질 때 $a$의 값은?

> 풀이: 인수정리에 의해 $f(2) = 0$
>
> $8 + 2a + 4 = 0$, $a = -6$

**예제 3.** $f(x)$를 $x - 1$로 나눈 나머지가 $3$, $x - 2$로 나눈 나머지가 $5$입니다. $f(x)$를 $(x - 1)(x - 2)$로 나눈 나머지는?

> 풀이: 이차식으로 나눈 나머지는 일차 이하이므로 $ax + b$로 둡니다.
>
> $f(x) = (x - 1)(x - 2)Q(x) + ax + b$
>
> $x = 1$ 대입: $f(1) = a + b = 3$
>
> $x = 2$ 대입: $f(2) = 2a + b = 5$
>
> 연립하면 $a = 2$, $b = 1$. 나머지는 $2x + 1$

## 연습문제

1. 모든 $x$에 대하여 $ax^2 + (b - 1)x + 3 = 2x^2 + 4x + c$일 때 $a$, $b$, $c$는?
2. $f(x) = x^2 - 4x + 7$을 $x - 3$으로 나눈 나머지는?
3. $f(x) = x^3 + 2x^2 - x + 1$을 $x + 2$로 나눈 나머지는?
4. $f(x) = 4x^2 - 2x + 1$을 $2x - 1$로 나눈 나머지는?
5. $x^3 - 2x^2 + kx + 6$이 $x + 1$로 나누어떨어질 때 $k$는?
6. $f(x)$를 $x + 1$로 나눈 나머지가 $-1$, $x - 3$으로 나눈 나머지가 $7$일 때, $f(x)$를 $(x + 1)(x - 3)$으로 나눈 나머지는?

## 정답과 풀이

1. $a = 2$, $b = 5$, $c = 3$
2. $4$ ($9 - 12 + 7$)
3. $3$ ($-8 + 8 + 2 + 1$)
4. $1$ ($f\!\left(\frac{1}{2}\right) = 1 - 1 + 1$)
5. $k = 3$ ($f(-1) = -1 - 2 - k + 6 = 3 - k = 0$)
6. $2x + 1$ ($-a + b = -1$, $3a + b = 7$ → $a = 2$, $b = 1$)
