# 2. 문자와 식 정리하기

> **먼저 알아야 할 것**: [1. 음수와 분수, 다시 계산하기](01-numbers.md)
>
> **한 줄 요약**: $x$는 "아직 모르는 수"를 잠시 넣어 두는 빈 상자입니다.

## 왜 문자를 쓸까요?

"사과 한 개 값을 모르는데, 사과 3개를 사면 얼마일까?"

값을 모르니 숫자로 쓸 수 없습니다. 그래서 모르는 값을 $x$라고 이름 붙이면

$$
\text{사과 3개 값} = 3 \times x
$$

처럼 쓸 수 있습니다. 문자는 **숫자 자리를 맡아 두는 빈 상자**일 뿐, 특별히 어려운 것이 아닙니다.

## 문자식을 쓰는 약속

| 원래 모양 | 줄여 쓴 모양 | 약속 |
|---|---|---|
| $3 \times x$ | $3x$ | 곱셈 기호 $\times$는 생략 |
| $x \times 3$ | $3x$ | 숫자를 문자 앞에 |
| $1 \times x$ | $x$ | 1은 생략 |
| $(-1) \times x$ | $-x$ | $-1$은 $-$만 남김 |
| $x \times x$ | $x^2$ | 같은 문자 곱은 거듭제곱 |
| $x \div 2$ | $\dfrac{x}{2}$ | 나눗셈은 분수로 |

## 식의 값 구하기: 상자에 숫자 넣기

$x = 3$일 때 $2x + 1$의 값은?

$$
2x + 1 = 2 \times 3 + 1 = 7
$$

음수를 넣을 때는 **반드시 괄호**를 치세요.

$x = -3$일 때 $x^2$의 값은?

$$
x^2 = (-3)^2 = 9 \quad (\text{O}), \qquad -3^2 = -9 \quad (\text{X})
$$

## 용어 몇 가지

$3x^2 - 5x + 2$라는 식을 예로 들어 볼게요.

- **항**: 더하기로 나뉜 각 덩어리. $3x^2$, $-5x$, $2$ (빼기는 "음수를 더한다"로 봅니다)
- **계수**: 문자 앞에 곱해진 숫자. $x^2$의 계수는 $3$, $x$의 계수는 $-5$
- **상수항**: 문자 없이 숫자만 있는 항. $2$
- **차수**: 문자가 곱해진 개수. $3x^2$은 2차, $-5x$는 1차
- **동류항**: 문자와 차수가 똑같은 항. $2x$와 $-7x$는 동류항, $2x$와 $2x^2$은 동류항이 **아님**

## 식 정리하기: 같은 것끼리 모으기

**동류항끼리만 더하고 뺄 수 있습니다.** 사과는 사과끼리, 배는 배끼리 셉니다.

$$
3x + 2 + 5x - 7 = (3x + 5x) + (2 - 7) = 8x - 5
$$

$3x$와 $x^2$은 서로 다른 과일이라서 더할 수 없습니다.

$$
3x + x^2 \quad \text{(더 이상 정리 안 됨)}
$$

## 괄호 풀기: 분배법칙

괄호 앞의 수는 괄호 안의 **모든 항에** 곱해집니다.

$$
3(x + 2) = 3x + 6
$$

$$
-2(x - 4) = -2x + 8
$$

> 💡 **가장 흔한 실수**: 괄호 앞이 마이너스일 때 뒤쪽 항의 부호를 안 바꾸는 것
>
> $-(x - 4) = -x + 4$ (O), $-(x - 4) = -x - 4$ (X)

## 예제

**예제 1.** $2(3x - 1) - (x + 5)$를 정리하세요.

> 풀이: 괄호를 풀면 $6x - 2 - x - 5$
>
> 동류항끼리 모으면 $(6x - x) + (-2 - 5) = 5x - 7$

**예제 2.** $a = -2$, $b = 3$일 때 $a^2 - 2ab$의 값을 구하세요.

> 풀이: $(-2)^2 - 2 \times (-2) \times 3 = 4 - (-12) = 4 + 12 = 16$

## 연습문제

1. $4x - 7x + 2$를 정리하세요.
2. $5(2a + 1)$의 괄호를 푸세요.
3. $-3(x - 2y + 1)$의 괄호를 푸세요.
4. $3(x + 2) - 2(x - 1)$을 정리하세요.
5. $\dfrac{x + 1}{2} + \dfrac{x - 1}{3}$을 정리하세요.
6. $x = -1$일 때 $2x^2 - 3x + 1$의 값을 구하세요.

## 정답과 풀이

1. $-3x + 2$
2. $10a + 5$
3. $-3x + 6y - 3$
4. $x + 8$ ($3x + 6 - 2x + 2$)
5. $\dfrac{5x + 1}{6}$ (통분: $\dfrac{3(x+1) + 2(x-1)}{6} = \dfrac{3x + 3 + 2x - 2}{6}$)
6. $6$ ($2 \times (-1)^2 - 3 \times (-1) + 1 = 2 + 3 + 1$)
