# 7. 함수와 합성함수, 역함수

> **먼저 알아야 할 것**: [0단계 4. 함수가 뭐예요?](../basics/04-functions.md), [5. 집합](05-sets.md)
>
> **한 줄 요약**: 합성함수는 기계 두 대를 이어 붙인 것, 역함수는 기계를 거꾸로 돌린 것입니다.

## 함수 다시 보기: 정의역, 공역, 치역

[0단계](../basics/04-functions.md)에서 함수는 "넣으면 **딱 하나** 나오는 기계"라고 했습니다. 이제 집합의 언어로 정확히 말해 봅시다.

집합 $X$의 각 원소에 집합 $Y$의 원소가 **하나씩** 대응할 때, 이것을 $X$에서 $Y$로의 함수라 하고 $f: X \to Y$로 씁니다.

- **정의역** $X$: 넣을 수 있는 값들
- **공역** $Y$: 나올 수 **있는** 값들의 후보
- **치역**: 실제로 나온 값들 ($f(x)$들의 모임, 공역의 부분집합)

**예)** $X = \{1, 2, 3\}$, $Y = \{1, 2, 3, 4, 5, 6\}$, $f(x) = 2x$

치역은 $\{2, 4, 6\}$입니다. 1, 3, 5는 공역에 있지만 나오지 않았어요.

> 💡 **함수인지 판단하기**: 정의역의 원소가 **남김없이**, 그리고 **하나씩만** 화살표를 쏘면 함수입니다. 화살표를 안 쏘는 원소가 있거나 두 개를 쏘는 원소가 있으면 함수가 아니에요.

## 일대일함수와 일대일대응

- **일대일함수**: 서로 다른 값을 넣으면 **항상 서로 다른 값**이 나옴 ($x_1 \neq x_2$이면 $f(x_1) \neq f(x_2)$)
- **일대일대응**: 일대일함수이면서 **치역 = 공역** (공역에 남는 원소가 없음)

예) $f(x) = 2x + 1$ (실수 전체 → 실수 전체)은 일대일대응. $f(x) = x^2$은 $f(1) = f(-1)$이라서 일대일함수가 아님.

## 합성함수: 기계 이어 붙이기

$x$를 기계 $f$에 넣고, 나온 결과를 다시 기계 $g$에 넣는 것을 **합성함수** $g \circ f$라고 합니다.

$$
(g \circ f)(x) = g(f(x))
$$

> 💡 **오른쪽 것부터** 계산합니다. $g \circ f$는 $f$ 먼저, 그다음 $g$. 안쪽 괄호부터 푼다고 생각하세요.

**예)** $f(x) = x + 1$, $g(x) = x^2$일 때

$$
(g \circ f)(2) = g(f(2)) = g(3) = 9
$$

$$
(f \circ g)(2) = f(g(2)) = f(4) = 5
$$

순서를 바꾸면 결과가 다릅니다. 일반적으로 $g \circ f \neq f \circ g$

식으로 구하면

$$
(g \circ f)(x) = g(x + 1) = (x + 1)^2
$$

$$
(f \circ g)(x) = f(x^2) = x^2 + 1
$$

## 역함수: 기계를 거꾸로

$f$가 $x$를 $y$로 보낸다면, **$y$를 다시 $x$로 되돌려 보내는** 함수를 $f$의 **역함수** $f^{-1}$라고 합니다.

$$
f(a) = b \iff f^{-1}(b) = a
$$

> 💡 $f^{-1}$은 $\dfrac{1}{f}$가 **아닙니다!** "거꾸로 함수"라는 기호일 뿐이에요.

역함수가 존재하려면 $f$가 **일대일대응**이어야 합니다. 거꾸로 돌렸을 때도 딱 하나로 돌아가야 하니까요.

### 역함수 구하는 법

1. $y = f(x)$로 놓는다.
2. $x$에 대해 푼다. ($x = \cdots$)
3. $x$와 $y$를 **맞바꾼다**.

**예)** $f(x) = 2x + 1$의 역함수

$y = 2x + 1$ → $x = \dfrac{y - 1}{2}$ → $x$, $y$ 바꾸면 $y = \dfrac{x - 1}{2}$

$$
f^{-1}(x) = \frac{x - 1}{2}
$$

확인: $f(3) = 7$, $f^{-1}(7) = \dfrac{7 - 1}{2} = 3$ ✔ 원래대로 돌아왔어요.

### 역함수의 그래프

$x$와 $y$를 맞바꿨으니, $y = f^{-1}(x)$의 그래프는 $y = f(x)$의 그래프를 **직선 $y = x$에 대하여 대칭이동**한 것입니다. ([도형의 이동](04-transformations.md) 참고)

### 중요한 성질

$$
(f^{-1} \circ f)(x) = x, \qquad (f \circ f^{-1})(x) = x
$$

갔다가 되돌아오면 제자리입니다.

## 예제

**예제 1.** $f(x) = 3x - 2$, $g(x) = x^2 + 1$일 때 $(f \circ g)(1)$과 $(g \circ f)(x)$

> 풀이: $(f \circ g)(1) = f(g(1)) = f(2) = 4$
>
> $(g \circ f)(x) = g(3x - 2) = (3x - 2)^2 + 1 = 9x^2 - 12x + 5$

**예제 2.** $f(x) = \dfrac{1}{3}x + 2$의 역함수는?

> 풀이: $y = \dfrac{1}{3}x + 2$ → $x = 3(y - 2) = 3y - 6$ → $f^{-1}(x) = 3x - 6$

**예제 3.** $f(x) = 2x - 5$일 때 $f^{-1}(3)$은?

> 풀이: 역함수를 구하지 않아도 됩니다. $f^{-1}(3) = a$이면 $f(a) = 3$
>
> $2a - 5 = 3$ → $a = 4$

## 연습문제

1. $X = \{-1, 0, 1\}$에서 $f(x) = x^2$의 치역
2. $f(x) = x - 3$, $g(x) = 2x$일 때 $(g \circ f)(5)$, $(f \circ g)(5)$
3. 문제 2에서 $(g \circ f)(x)$, $(f \circ g)(x)$
4. $f(x) = 4x + 8$의 역함수
5. $f(x) = -x + 3$의 역함수 (어떤 특징이 있나요?)
6. $f(x) = 3x + 1$일 때 $f^{-1}(10)$
7. 다음 중 일대일대응인 것은? (실수 전체 → 실수 전체) (가) $y = 3x$ (나) $y = x^2$ (다) $y = 5$

## 정답과 풀이

1. $\{0, 1\}$
2. $4$ ($g(2)$), $7$ ($f(10)$)
3. $2x - 6$, $2x - 3$
4. $f^{-1}(x) = \dfrac{1}{4}x - 2$
5. $f^{-1}(x) = -x + 3$ (자기 자신이 역함수! 그래프가 $y = x$에 대칭이기 때문)
6. $3$ ($3a + 1 = 10$)
7. (가)
