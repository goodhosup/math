# 2. 확률의 뜻과 덧셈정리

> **먼저 알아야 할 것**: [1. 순열과 조합 심화](01-permutations-combinations.md), [공통수학2 5. 집합](../common2/05-sets.md)
>
> **한 줄 요약**: 확률 = (원하는 경우의 수) ÷ (전체 경우의 수). "또는"은 더하고 겹친 것은 빼며, "적어도"는 1에서 뺍니다.

## 용어 정리

- **시행**: 같은 조건에서 반복할 수 있는 실험 (주사위 던지기 등)
- **표본공간** $S$: 일어날 수 있는 모든 결과의 집합. 주사위면 $S = \{1, 2, 3, 4, 5, 6\}$
- **사건**: 표본공간의 부분집합. "짝수가 나온다" = $\{2, 4, 6\}$

확률은 [집합](../common2/05-sets.md)의 언어로 다룹니다.

## 수학적 확률

모든 결과가 일어날 가능성이 **똑같을 때**, 사건 $A$의 확률은

$$
P(A) = \frac{n(A)}{n(S)} = \frac{\text{사건 } A\text{의 경우의 수}}{\text{전체 경우의 수}}
$$

예) 주사위를 던져 짝수가 나올 확률: $\dfrac{3}{6} = \dfrac{1}{2}$

예) 동전 2개를 던져 모두 앞면일 확률: 전체 (앞앞, 앞뒤, 뒤앞, 뒤뒤) 4가지 중 1가지 → $\dfrac{1}{4}$

> 💡 동전 2개의 결과를 "둘 다 앞, 하나만 앞, 둘 다 뒤" 3가지로 세면 틀립니다. 이 세 경우는 가능성이 같지 않아요. **동전도 구별해서** 세야 합니다.

## 통계적 확률

같은 시행을 아주 많이 반복했을 때, 사건이 일어난 **비율**이 일정한 값에 가까워지면 그 값을 확률로 봅니다.

예) 압정을 1000번 던져 바늘이 위로 향한 것이 620번 → 확률 약 $0.62$

## 확률의 기본 성질

$$
0 \le P(A) \le 1, \qquad P(S) = 1, \qquad P(\varnothing) = 0
$$

- 반드시 일어나는 사건의 확률은 $1$
- 절대 일어나지 않는 사건의 확률은 $0$

## 덧셈정리: "또는"

사건 $A$ **또는** $B$가 일어날 확률은 [합집합의 원소 개수](../common2/05-sets.md)와 같은 원리입니다.

$$
P(A \cup B) = P(A) + P(B) - P(A \cap B)
$$

겹친 부분을 두 번 세지 않도록 한 번 뺍니다.

예) 1부터 20까지 카드 중 하나를 뽑을 때 2의 배수 또는 3의 배수일 확률

- 2의 배수: 10개, 3의 배수: 6개, 6의 배수(둘 다): 3개
- $\dfrac{10}{20} + \dfrac{6}{20} - \dfrac{3}{20} = \dfrac{13}{20}$

두 사건이 동시에 일어날 수 없으면(**배반사건**, $A \cap B = \varnothing$) 그냥 더하면 됩니다.

$$
P(A \cup B) = P(A) + P(B)
$$

## 여사건: "적어도"는 1에서 빼기

사건 $A$가 일어나지 **않는** 사건을 여사건 $A^C$라고 합니다.

$$
P(A^C) = 1 - P(A)
$$

> 💡 문제에 "**적어도 하나**", "**~이 아닐**"이 나오면 여사건을 떠올리세요. 직접 세면 경우가 많지만, 반대쪽은 하나뿐인 경우가 많습니다.

예) 동전 3개를 던질 때 적어도 1개가 앞면일 확률

반대: 모두 뒷면 → $\dfrac{1}{8}$. 따라서 $1 - \dfrac{1}{8} = \dfrac{7}{8}$

## 조합을 이용한 확률

뽑는 문제는 전체와 원하는 경우를 **둘 다 조합으로** 셉니다.

예) 빨간 공 4개, 파란 공 3개가 든 주머니에서 2개를 동시에 꺼낼 때 둘 다 빨간 공일 확률

$$
\frac{{}_4\mathrm{C}_2}{{}_7\mathrm{C}_2} = \frac{6}{21} = \frac{2}{7}
$$

## 예제

**예제 1.** 주사위 2개를 던질 때 눈의 합이 7일 확률

> 풀이: 전체 $36$가지. 합 7: (1,6), (2,5), (3,4), (4,3), (5,2), (6,1) → $6$가지
>
> $\dfrac{6}{36} = \dfrac{1}{6}$

**예제 2.** A, B, C, D, E 5명을 일렬로 세울 때 A가 맨 앞에 설 확률

> 풀이: 전체 $5! = 120$, A가 맨 앞: 나머지 $4! = 24$ → $\dfrac{24}{120} = \dfrac{1}{5}$

**예제 3.** 남자 5명, 여자 3명 중 3명을 뽑을 때 적어도 1명이 여자일 확률

> 풀이: 모두 남자일 확률 $\dfrac{{}_5\mathrm{C}_3}{{}_8\mathrm{C}_3} = \dfrac{10}{56} = \dfrac{5}{28}$
>
> $1 - \dfrac{5}{28} = \dfrac{23}{28}$

## 연습문제

1. 주사위 1개를 던질 때 3의 배수가 나올 확률
2. 동전 3개를 던질 때 앞면이 정확히 2개 나올 확률
3. 1부터 10까지 카드 중 하나를 뽑을 때 짝수 또는 3의 배수일 확률
4. 주사위 2개를 던질 때 두 눈이 서로 다를 확률
5. 흰 공 3개, 검은 공 2개 중 2개를 꺼낼 때 서로 다른 색일 확률
6. $P(A) = 0.5$, $P(B) = 0.4$, $P(A \cap B) = 0.2$일 때 $P(A \cup B)$와 $P(A^C)$

## 정답과 풀이

1. $\dfrac{1}{3}$ ($\{3, 6\}$)
2. $\dfrac{3}{8}$ (앞앞뒤, 앞뒤앞, 뒤앞앞)
3. $\dfrac{7}{10}$ ($\dfrac{5}{10} + \dfrac{3}{10} - \dfrac{1}{10}$, 둘 다인 것은 6)
4. $\dfrac{5}{6}$ (같을 확률 $\dfrac{6}{36}$을 1에서 뺌)
5. $\dfrac{3}{5}$ ($\dfrac{3 \times 2}{{}_5\mathrm{C}_2} = \dfrac{6}{10}$)
6. $0.7$, $0.5$
