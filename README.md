# 수포자를 위한 고등수학

수학을 포기했던 사람도 처음부터 다시 시작할 수 있는 쉬운 고등학교 수학 안내서입니다.

- 웹사이트(GitHub Pages): https://goodhosup.github.io/math/
- 원본 마크다운: [`docs/`](docs/) 폴더 (위키독스에 그대로 옮겨 실을 수 있습니다)

## 폴더 구성

```
docs/
├── index.md              소개
├── how-to-study.md       공부법
├── curriculum.md         전체 커리큘럼
├── basics/               0단계: 기초 다지기 (중학 핵심)
├── common1/              1단계: 공통수학1
└── images/               그림 파일
mkdocs.yml                웹사이트 설정 (메뉴 순서는 여기 nav에서)
```

## 위키독스에 올리는 방법

1. 위키독스에서 책을 만들고, 커리큘럼 순서대로 페이지를 만듭니다.
2. `docs/` 안의 `.md` 파일 내용을 각 페이지 편집창에 그대로 붙여 넣습니다.
3. 수식은 `$...$`(문장 안), `$$...$$`(가운데 정렬) 형식이라 위키독스의 수식 기능으로 그대로 보입니다.
4. 그림(`images/` 폴더의 `.svg`)은 위키독스 편집기에서 이미지로 업로드한 뒤 링크를 바꿔 주세요.
5. 페이지끼리의 링크(`01-numbers.md` 같은 상대 경로)는 위키독스 페이지 주소로 바꿔 주세요.

## 내 컴퓨터에서 미리 보기

```bash
pip install -r requirements.txt
mkdocs serve
```

브라우저에서 http://127.0.0.1:8000 을 열면 됩니다. `main` 브랜치에 올리면 GitHub Actions가 자동으로 사이트를 다시 배포합니다.

## 새 단원 추가하기

1. `docs/` 아래 알맞은 폴더에 `.md` 파일을 만듭니다. (기존 단원의 구성을 따라 주세요: 먼저 알아야 할 것 → 한 줄 요약 → 개념 → 예제 → 연습문제 → 정답과 풀이)
2. `mkdocs.yml`의 `nav`에 추가합니다.
3. `docs/curriculum.md`에서 해당 단원을 ✅로 바꾸고 링크를 겁니다.
